5. Key learning outcomes

  • VPC Peering allows private IPv4 communication between two VPCs.
  • Both VPC route tables need routes to the remote CIDR.
  • Security groups must allow the required traffic.
  • VPC Peering is not transitive.
  • A bastion host can provide controlled SSH access to private instances.
